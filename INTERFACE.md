# Math Course -- Interface Map

## Module Overview

| File | Purpose | Key Classes |
|------|---------|-------------|
| `ancient_numbers.py` | Egyptian and Babylonian number systems | `EgyptianNumber`, `BabylonianNumber` |
| `ancient_calculations.py` | Egyptian multiplication, Babylonian square root | `EgyptianMultiplication`, `BabylonianSquareRoot` |
| `ancient_math_visualization.py` | Visualization of ancient math concepts | `AncientMathVisualizer` |
| `world_numbers.py` | Roman, Mayan, Chinese numeral systems | `RomanNumeral`, `MayanNumeral`, `ChineseNumeral` |
| `number_theory_basics.py` | GCD, primes, sieve, factorization | `NumberTheory` |
| `bio_math_patterns.py` | Fibonacci, golden ratio in biology | `BioMathPatterns` |
| `bio_math_enhanced.py` | Enhanced Fibonacci analysis and pattern analysis | `FibonacciAnalyzer`, `MathematicalPatternAnalyzer` |
| `bio_growth_patterns.py` | Biological growth modeling (trees) | `TreeNode`, `BioGrowthPatterns` |
| `bio_number_theory.py` | Number theory applied to biology | `BioNumberTheory` |
| `bio_sequence_analysis.py` | DNA/protein sequence analysis | `NCBISequenceAnalyzer` |
| `shell_growth_patterns.py` | Shell spiral growth models | `ShellParameters`, `ShellGrowthAnalysis` |
| `shell_comparative_analysis.py` | Comparative shell measurements | `ShellMeasurement`, `ShellComparativeAnalysis` |
| `tree_data_analysis.py` | Tree branching data analysis | `TreeDataAnalysis` |
| `advanced_tree_patterns.py` | Advanced tree branching models | `TreeNode`, `AdvancedTreeModel` |
| `ip3r_analysis.py` | IP3 receptor calcium signaling analysis | `IP3RAnalyzer` |
| `math_bio_demo.py` | Demo/showcase of math-bio integration | (script) |
| `test_math_course.py` | Unit tests | (tests) |

## Notes

- Hyphenated originals (e.g., `ancient-numbers.py`) are preserved for backward compatibility.
  The underscore versions (e.g., `ancient_numbers.py`) are the importable copies.
- `bio_math_enhanced.py` vs `bio_math_patterns.py`: enhanced version adds `FibonacciAnalyzer`
  and `MathematicalPatternAnalyzer` with more advanced analysis; patterns has the base `BioMathPatterns`.
